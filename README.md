# PAW

## Tasks con Minimal API

Se agrega PAW.MinimalAPI (.NET 10) con DI/IoC y acceso ADO.NET a dbo.Tasks, sin Entity Framework. El menú Tasks utiliza este proyecto para todo el CRUD y conserva el tipo de cambio flotante desde site.js. Configurar PAW.Web:MinimalApiBaseUrl y la conexión ProductDB del nuevo proyecto; iniciar PAW.MinimalAPI, PAW.API y PAW.Web. Ver PAW.MinimalAPI/README.md para endpoints y ejecución.
